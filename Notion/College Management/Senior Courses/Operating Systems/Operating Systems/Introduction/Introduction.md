  

# What is an OS?

- is software that manages a computer’s hardware. it is the one who manages the resources of the system.
- **A Program that acts as an intermediary between a user of a computer and the computer hardware**
- OS goals:
    - execute user programs and make solving user problems easier
    - make the computer system convenient to use
    - use the computer hardware in an efficient manner.

  

# Computer System Structure

- A computer system can be divided into four components:
    - **Hardware** - provides basic computing resources
    - **OS** - controls and coordinates use of hardware among various applications and users
    - **Application Programs** - defines the ways in which the system resources are used to solving the computing problems of the users
    - **Users**
- like a government, it performs no useful function by itself. it simply provides an environment within which other programs can do useful work.

# What Operating Systems Do

- Depends on the point of view
- Users want convenience, ease of use and good performance. they don’t care about resources utilization
- But shared computer such as mainframe and minicomputer must keep all users happy
    - OS is a resource allocator and control program making efficient use of the HW and managing execution of user programs
- users of dedicated systems such as workstations have dedicated resources but frequently use shared sources from servers
- mobile devices like smartphones and tablets are resource poor, optimized for usability and battery life
- some computers have little or no user interface, such as embedded computers in devices and automobiles.

# OS Definition

- No universally accepted definition
- “Everything a vendor ships when you order an OS” is a good approximation but varies wildly
- A more common definition is “the OS is the one program running at all times on the computer—usually called the **kernel**.”
- Everything else is either
    - a **system program** (ships with the OS, but not part of the kernel), or
    - an **application program**, all programs not associated with the OS
- Today’s OSes for general purpose and mobile computing also include middleware—a set of software frameworks that provide additional services to application developers such as databases, multimedia, and graphics.
