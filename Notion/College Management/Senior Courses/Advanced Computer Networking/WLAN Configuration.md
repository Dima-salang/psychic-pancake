
# The Wireless Router
- Remote workers, small branch offices, and home networks often use a small office and home router
	- These "integrated" routers typically include a switch for wired clients, a port for an internet connection (sometimes labeled WAN), and wireless components for wireless client access
	- these wireless routers typically provide WLAN security, DHCP services, integrated NAT, QoS, as well as a variety of other features
	- the features set will vary based on the router model
- Note: cable or DSL model configuration is usually done by the service provider's representative either on-site or remotely
